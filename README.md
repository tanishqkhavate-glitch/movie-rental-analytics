# Movie Rental Analytics

A complete data analysis project on the Sakila DVD Rental database.

## Tools Used
- PostgreSQL (EDA - 15 business questions)
- Microsoft Excel (Data exploration)
- Power BI (4 interactive dashboards)

## Project Structure
- `/dataset` — 18 raw CSV files
- `/eda` — SQL-based EDA with key insights
- `/powerbi` — Dashboard screenshots
- `/presentation` — Final PPT

## Key Findings
- Total Revenue: $67,406 from 16,044 rentals
- 97.5% customer retention rate
- Sports & Sci-Fi are top revenue categories
- Strong July 2005 seasonality (41% of revenue)
